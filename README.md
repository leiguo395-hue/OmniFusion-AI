# OmniFusion AI Android
Native Android prototype for OpenRouter. No model training or server needed.
Build with GitHub Actions: Actions > Build Android APK > Run workflow; download artifact `OmniFusion-debug-apk`.
On the phone, enter your own OpenRouter API key **inside the app only**. Never commit it to GitHub.
Default model: `openrouter/free`; free availability and quota vary.
Current scope: single-model chat, session-only conversation history, HTTPS requests. This is not yet multi-agent orchestration.
This is a debug build and has not yet passed device testing.
